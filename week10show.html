// 짧은 대화와 긴 작업

AI에게 오래 맡기면 생기는 일 네 가지

1 앞의 지시를 놓친다

예처음에 "색은 design.md 변수만"이라고 했는데, 대화가 길어지자 #7c3aed를 새로 씀

왜대화가 길어질수록 앞부분은 AI가 덜 챙김 · 오래된 내용은 요약되기도 함

→ 하네스에서AGENTS.md 규칙대화를 새로 열어도 처음에 다시 읽음

2 어디까지 했는지 모른다

예새 대화에서 이미 만든 사진 올리기를 처음부터 다시 만듦

왜새 대화는 앞 대화를 기억하지 못함 · 남은 것은 저장소의 파일뿐

→ 하네스에서tasks.md 상태커밋 기록과 함께 읽으면 이어서 함

3 한 번에 다 하려다 무너진다

예"앱 전체 만들어줘" → 파일 12개를 고치고 절반이 동작하지 않음

왜중간에 대화가 끊기면 반쯤 만든 기능이 기록 없이 남음

→ 하네스에서tasks.md 한 줄 = PR 하나작게 나눠서 하나씩 끝냄

4 확인 없이 다 됐다고 한다

예"완성했습니다!" → 브라우저 콘솔에 빨간 오류

왜코드를 읽고 맞다고 판단함 · 화면을 열어 실제로 눌러 보지 않음

→ 하네스에서checklist.md · 리뷰끝났다는 기준을 미리 적어 둠
