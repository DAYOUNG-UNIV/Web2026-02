## 실행 방법

```bash
git clone <저장소 주소>
cd <폴더 이름>
npx serve .
# 브라우저에서 http://localhost:3000
```

테스트: `npm i -D vitest` 한 번, 그 뒤 `npx vitest run`
빌드 단계: 없음 (있다면 명령과 순서를 적습니다)
환경 변수: 없음 (있다면 `.env.example`을 두고 변수 이름만 적습니다. 값은 적지 않습니다)
