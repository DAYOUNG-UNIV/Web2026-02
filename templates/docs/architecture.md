# architecture.md — 화면·데이터·폴더·기술

이 문서는 10주차에 씁니다. 팀 시트 ⑦(화면과 기술)을 옮겨 적고, 폴더 구조와 외부 서비스를 더합니다.
정답을 적는 문서가 아닙니다. 지금 아는 것과 알아볼 것을 구분해 적습니다. 11주차에 데이터 경로가 정해지면 고칩니다.

## 1. 화면 목록

한 화면 = 한 URL(또는 해시). GitHub Pages는 `/about` 같은 경로를 모르니 해시(`#about`)나 파일(`about.html`)로 나눕니다.

<details>
<summary>예시 · 메모 분류</summary>

| 이름 | 하는 일 | URL / 해시 |
|---|---|---|
| 입력 | 메모를 붙여 넣고 '나누기'를 누른다 | `/#input` |
| 카드 | 주제별 카드를 보고 옮긴다 | `/#cards` |
| 나란히 | 내 카드와 친구 카드를 두 열로 본다 | `/#compare?friend=sample` |

</details>

## 2. 화면 흐름

사용 장면 순서대로 화살표로 잇습니다. 되돌아가는 길도 적습니다.

<details>

## 3. 데이터

세 종류로 나눕니다. 받는 것(사용자가 입력), 남기는 것(다음에 와도 있어야 하는 것), 가져오는 것(밖에서 읽어 오는 것).
어디에 저장하는지는 메모리 · localStorage · 서버 중 하나입니다. 여러 사람·여러 기기·인증·비밀 키 중 하나라도 필요하면 서버(또는 서버리스·BaaS)입니다.

<details>
<summary>예시 · 메모 분류</summary>

| 종류 | 무엇 | 모양 | 어디에 저장 | 사는 기간 |
|---|---|---|---|---|
| 받는 것 | 붙여 넣은 메모 원문 | 문자열 | 메모리(state) | 나누기 전까지 |
| 남기는 것 | 주제별 카드와 옮긴 결과 | `[{ topic, lines[] }]` | localStorage `notes` | 브라우저를 지울 때까지 |
| 가져오는 것 | 친구가 나눈 결과 | 같은 모양의 JSON | `data/friend.json` (알파: 고정 파일, 나중에: 서버) | 요청할 때마다 |

```json
[
  { "topic": "정의", "lines": ["HTTP는 요청과 응답", "상태 코드 200·404"] },
  { "topic": "예시", "lines": ["GET /index.html"] }
]
```

</details>

| 종류 | 무엇 | 모양 | 어디에 저장 | 사는 기간 |
|---|---|---|---|---|
| 받는 것 | | | | |
| 남기는 것 | | | | |
| 가져오는 것 | | | | |

## 5. 외부 서비스와 키

쓰는 외부 서비스를 모두 적습니다. 키는 두 종류입니다.
비밀 키는 서버·서버리스의 환경 변수에만 둡니다. 커밋하지 않습니다. 노출되면 재발급합니다.
공개(제한) 키는 브라우저에 두어도 되지만 도메인 제한·보안 규칙(RLS 등)이 켜져 있어야 합니다.
판별 질문: "이 키로 남이 내 돈을 쓰거나 남의 데이터를 읽을 수 있나?" 그렇다면 비밀 키입니다.

<details>
<summary>예시 · 메모 분류</summary>

| 서비스 | 용도 | 키 종류 | 키를 두는 곳 | 장애 시 대비 |
|---|---|---|---|---|
| GitHub Pages | 배포 | 없음 | — | — |
| (나중에) Supabase | 친구 결과 공유 | 공개 키 + RLS | `config.js`(도메인 제한) | `data/friend.json`로 전환 |
| (검토 중) 생성형 AI API | 자동 분류 | 비밀 키 | 서버리스 함수 환경 변수 | 키워드 분류로 전환 |

</details>

| 서비스 | 용도 | 키 종류 | 키를 두는 곳 | 장애 시 대비 |
|---|---|---|---|---|
| GitHub Pages | 배포 | 없음 | — | — |

## 6. 기술

정답 칸이 아닙니다. '새로 알아볼 것'에는 누가 언제까지 알아보는지 적습니다.

<details>
<summary>예시 · 메모 분류</summary>

| 지금 아는 것으로 되는 것 | 새로 알아볼 것 | 누가 · 언제까지 |
|---|---|---|
| HTML·CSS로 입력·카드 화면 (3~5주차) | localStorage 저장·복원 | 팀원 3 · 11주차 |
| 배열을 카드로 그리기 (5주차 DOM) | fetch로 `friend.json` 읽기 | 팀원 1 · 11주차 |
| 해시로 화면 바꾸기 (9주차 심화) | 두 열 레이아웃을 모바일에서 한 열로 | 팀원 2 · 11주차 |
| | 여럿이 공유하려면 서버리스·BaaS 중 무엇 (선택 모듈) | 팀원 1 · 13주차, 결정표로 |

</details>
