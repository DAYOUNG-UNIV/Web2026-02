# requirements.md — 무엇을 만들까

이 문서는 10주차에 씁니다. 9주차 팀 시트의 ② ⑤ ⑥ ⑧을 옮겨 적습니다.
각 칸에는 예시(메모 분류 앱)가 접혀 있습니다. 펼쳐서 읽고, 아래 빈 칸을 우리 팀 내용으로 채웁니다.
범위가 바뀌면 이 문서를 먼저 고칩니다. AI 에이전트도 이 문서를 읽고 일합니다.

## 1. 팀 질문 (팀 시트 ②)

틀: ___한 사람이 ___할 때, 웹에서 ___하면 ___할까?

<details>
<summary>예시 · 메모 분류</summary>

> 수업 메모를 혼자만 보던 대학생이 시험 공부를 시작할 때, 웹에서 같은 메모를 친구가 나눈 결과와 나란히 놓아 보면 자기 메모를 다시 정리할까?

</details>

> ___한 사람이 ___할 때, 웹에서 ___하면 ___할까?

## 2. 팀 아이디어 한 문장 (팀 시트 ⑤)

틀: ___을(를) ___한다.

<details>
<summary>예시 · 메모 분류</summary>

> 붙여 넣은 수업 메모를 주제별 카드로 나누고, 친구가 나눈 결과와 나란히 보여 준다.

</details>

> ___을(를) ___한다.

## 3. 웹이어야 하는 이유

설치 없이, 링크로, 여러 기기에서, 여럿이 같이. 이 중 우리 프로젝트에 해당하는 것을 한두 줄로 적습니다.

<details>
<summary>예시 · 메모 분류</summary>

- 링크 하나로 친구와 같은 메모를 봅니다. 앱 설치가 없습니다.
- 수업 중에는 폰으로, 시험 기간에는 노트북으로 같은 메모를 엽니다.

</details>

## 4. 사용 장면 (팀 시트 ⑥)

들어와서 나갈 때까지 3~5단계. 장면에는 한 사람만 나옵니다. 팀 질문의 '무엇을 하면' 단계에 ★를 붙입니다.

<details>
<summary>예시 · 메모 분류</summary>

| 단계 | 사용자가 하는 일 | 화면에서 일어나는 일 | ★ |
|---|---|---|---|
| 1 | 수업 메모를 입력창에 붙여 넣는다 | 글자 수와 '나누기' 버튼이 보인다 | |
| 2 | '나누기'를 누른다 | 메모가 주제별 카드 3~5개로 나뉘어 보인다 | ★ |
| 3 | 친구의 링크를 연다 | 내 카드와 친구 카드가 두 열로 나란히 보인다 | |
| 4 | 카드 하나를 다른 주제로 옮긴다 | 바뀐 분류가 저장되고 '정리됨' 표시가 뜬다 | |
| 5 | 내 링크를 복사한다 | '복사됨' 안내가 보인다 | |

</details>

| 단계 | 사용자가 하는 일 | 화면에서 일어나는 일 | ★ |
|---|---|---|---|

| 2 | | | |

## 5. 알파 버전 범위 (팀 시트 ⑧)

알파 = 사용 장면을 처음부터 끝까지 한 번 지나가는 가장 작은 버전. ★ 단계만 실제로 동작하고, 나머지는 가짜 데이터나 사람이 대신합니다.

<details>
<summary>예시 · 메모 분류</summary>

| 꼭 넣을 것 (★ 단계, 시작과 끝) | 가짜로 둘 것 | 나중에 할 것 |
|---|---|---|
| 1 붙여 넣기 → 2 ★나누기 → 4 옮기기 | 3 친구 결과: `data/friend.json` 고정 파일 | 링크 공유(5) |
| 나누기 규칙: 키워드 목록 5개로 단순하게 | 저장: localStorage(서버 없음) | 로그인, AI 분류 |

</details>

| 꼭 넣을 것 (★ 단계, 시작과 끝) | 가짜로 둘 것 | 나중에 할 것 |
|---|---|---|

## 6. 확인할 것 한 줄

알파가 되었는지 눈으로 확인할 수 있는 한 문장. 팀 질문과 이어져야 합니다.

<details>
<summary>예시 · 메모 분류</summary>

> 처음 본 사람이 메모를 붙여 넣고, 1분 안에 카드 하나를 다른 주제로 옮긴다.

</details>
