# tasks.md — 지금 무엇을 할까

이 문서는 10주차부터 매주 씁니다. 팀 시트 ⑨(누가 무엇을)를 옮겨 적고, 스튜디오 끝에 갱신합니다.
AI 에이전트에게 일을 맡길 때도 이 표의 한 줄을 가리킵니다.

## 규칙

- 한 줄 = 한 PR. 한 줄이 PR 하나로 끝나지 않으면 줄을 나눕니다.
- '이번 주에 보여 줄 것'은 완료 기준입니다. 눈으로 확인할 수 있는 한 문장으로 적습니다. "잘 되게"는 완료 기준이 아닙니다.
- 매주 갱신합니다. 끝난 줄은 지우지 말고 상태를 '완료'로 바꿉니다. 다음 주 줄을 위에 더합니다.
- 상태는 네 가지만 씁니다. 시작 전 · 진행 중 · 리뷰 중 · 완료.
- 마지막 줄 'YOUR CODE 1분'은 매주 돌아가며 맡습니다. 이번 주 AI가 만든 코드·문서 한 조각을 팀 앞에서 1분 설명합니다. 설명이 안 되면 "지금 배운 문법으로 풀어 써 달라고 요청하기"를 다음 주 할 일로 적습니다.
