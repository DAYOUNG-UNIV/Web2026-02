# demo-feedback.md — 시연회 피드백

14주차 시연회 뒤 스튜디오에서 씁니다. 받은 TAG와 투표를 정리하고, 15주차까지 고칠 것 3개를 정한 뒤 범위를 동결합니다.
피드백을 준 사람의 실명은 적지 않습니다. "다른 팀", "강사"처럼 적습니다.

## 1. TAG 요약

같은 말이 여러 번 나오면 횟수를 적습니다. 한 번 나온 말도 버리지 않고 적습니다.

## 5. 동결 범위

15주차 제출까지 허용하는 작업은 세 가지뿐입니다.

- [ ] 버그 수정 (위 표의 1~3)
- [ ] 문서 (README, docs/, 발표 자료)
- [ ] 아카이빙 (영상, 릴리스 태그, 브랜치 정리)

새 기능·구조 변경·새 라이브러리는 넣지 않습니다. 동의한 팀원: 팀원 1 · 팀원 2 · 팀원 3
