# alpha-test.md — 알파 테스트

11주차 스튜디오에서 카드를 쓰고, 12주차에 다른 팀 2~3명에게 테스트를 받아 기록하고, 13주차에 정리해 Issue로 옮깁니다.
공개 저장소이므로 테스터는 '테스터 1'처럼 적습니다. 실명·학번을 쓰지 않습니다.

## 2. 진행 규칙

- 설명하지 않습니다. 할 일만 말합니다. 화면이 스스로 설명해야 합니다.
- 테스터는 소리 내어 생각하며 합니다. "지금 뭘 찾고 있어요?"만 물어봅니다.
- 돕지 않습니다. 막히면 어디서 막혔는지 적습니다. 1분 넘게 막히면 "다음으로 넘어가 주세요"라고 합니다.
- 끝나고 TAG를 받습니다. T 좋았던 점 · A 궁금한 점 · G 제안할 점, 각 한 줄.
- 역할: 진행자 1명(말하기), 관찰자 1명(적기). 나머지 팀원은 끼어들지 않습니다.
- 2~3명이면 충분합니다. 같은 곳에서 두 명이 막히면 고칠 곳입니다.
