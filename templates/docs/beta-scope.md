## 4. 배포 점검 체크리스트

시연 전날과 당일 아침, 두 번 확인합니다. 확인한 사람 이름을 옆에 적습니다.

- [ ] 배포 링크가 시크릿 창에서 열린다. (링크: )
- [ ] 경로: 저장소 이름이 URL에 들어가도 (`/저장소이름/`) 페이지가 열린다.
- [ ] 상대 주소: CSS·JS·이미지·JSON이 `/style.css`가 아니라 `./style.css`처럼 상대 주소다. 콘솔에 404가 없다.
- [ ] 404: 해시(`#cards`)로 화면을 바꾸거나, 새로고침해도 404가 나지 않는다.
- [ ] 비밀 커밋: 저장소 전체에서 키·토큰·`.env`를 검색해 없다. `.gitignore`에 `.env`가 있다.
- [ ] BaaS 깨우기: 무료 플랜의 일시정지를 전날 풀고, 당일 아침 한 번 요청해 본다.
- [ ] 외부 API 한도: 시연 중 요청 수가 한도 안이다. 429가 나면 오프라인 데이터로 넘어간다.
- [ ] 시드 데이터에 실명·연락처·실제 메모가 없다.
- [ ] 모바일 폭과 발표용 화면(큰 글자) 두 가지로 열어 봤다.
- [ ] 대비책 3개를 실제로 켜 봤다.
