ChatGPT Edu 따라 하기

학교가 모든 학생에게 제공하는 ChatGPT Edu를 수업의 기본 AI 도구로 씁니다. 세 가지 연습 화면에서 요구사항 초안, 코드 설명과 버그 찾기, 발표 스크립트를 직접 요청해 보고, 받은 답을 설명·검증·판단하는 순서를 몸에 익힙니다. 연습 화면은 로그인 없이 동작하며 실제 서비스가 아닙니다.

이 매뉴얼이 맞는 경우

잘 맞는 경우
  • 모든 과제에서 설명, 초안, 오류 원인, 리뷰를 받고 싶을 때. 학교 계정으로 쓸 수 있는 기본 도구입니다.
  • 팀 시트와 문서를 한곳(프로젝트)에 모아 두고 같은 맥락으로 여러 번 묻고 싶을 때.
과한 경우
  • 파일 여러 개를 직접 고치고 테스트까지 돌리게 하고 싶을 때는 코딩 에이전트(Codex 또는 Claude Code)가 맞습니다. 다만 어느 것도 과제의 필수 조건이 아닙니다.
  • 비밀 키나 개인정보가 든 자료를 다뤄야 할 때. 이런 자료는 어떤 AI 도구에도 넣지 않습니다.
먼저 할 것
학교 안내(eTL 공지)대로 ChatGPT Edu에 로그인합니다. 이 페이지의 연습 화면은 로그인 없이 됩니다.

진행 상황을 표시하며 따라가세요. 표시는 이 브라우저에만 저장됩니다.

ChatGPT Edu란

이 절을 읽고 나면 "학습에 쓰지 않는다"와 "학교가 볼 수 없다"가 다른 말이라는 것을 설명할 수 있습니다.

OpenAI는 ChatGPT Edu를 이렇게 소개합니다. "ChatGPT Edu is designed for schools that want to deploy AI more broadly to students and their campus communities." 학교가 계약한 워크스페이스 안에서 학생이 쓰는 ChatGPT입니다. 우리 수업에서는 모든 학생이 같은 조건으로 쓸 수 있는 이 도구를 기본으로 둡니다. 유료 도구를 쓰는지 여부는 평가에 영향을 주지 않습니다.

학습에 쓰지 않음
OpenAI 기업 개인정보 문서의 원문은 "We do not train our models on your data by default"입니다. Edu도 여기에 포함됩니다.
내 데이터는 내 것
"You own and control your data". 입력과 출력에 대한 권리는 사용자(학교) 쪽에 있습니다.
관리자가 볼 수 있음
워크스페이스 관리자는 컴플라이언스 도구로 대화 기록에 접근할 수 있습니다. 보존 기간도 관리자가 정합니다.
공유는 학교 안에서만
대화 공유 링크는 같은 워크스페이스 구성원만 열 수 있습니다. 문서 원문: "Chats can't be shared outside the workspace."
한도는 학교 설정
메시지·크레딧 한도는 학교 계약과 관리자 설정에 따릅니다. 공식 문서에 숫자가 없습니다.

YOUR CODE, YOUR RESPONSIBILITY

AI가 만들어도 제출하는 사람은 나입니다. 다음 다섯 가지를 자기 말로 설명할 수 있어야 합니다.

  1. 구조 파일과 함수가 어떻게 나뉘어 있는가
  2. 동작 입력이 들어오면 어떤 순서로 무엇이 바뀌는가
  3. 선택 이유 왜 이 방법을 골랐고 다른 방법은 왜 버렸는가
  4. 테스트 무엇을 어떻게 확인했는가
  5. 한계·위험 어디서 깨질 수 있고 무엇을 아직 못 했는가

금지선 네 가지

검증 없는 제출
실행해 보지 않은 코드, 읽어 보지 않은 문서를 그대로 내지 않습니다.
비밀정보 입력
API 키, 비밀번호, 학생 실명, 연락처를 프롬프트나 첨부 파일에 넣지 않습니다. Edu의 학습 미사용 원칙과 별개입니다.
확인 안 한 정보·출처
AI가 댄 수치·인용·링크는 직접 열어 확인합니다. 문서 원문: "Use ChatGPT as a first draft, not a final source."
무조건적 에이전트 권한
코딩 에이전트에게 "다시 묻지 않기"를 모든 명령에 주지 않습니다. ChatGPT Edu 웹에서는 해당 없음, 에이전트 매뉴얼에서 다룹니다.

AI가 다 해 줘도 되나요?

됩니다. 단 세 가지를 할 수 있어야 합니다. 설명(이 코드가 무엇을 하는지 내 말로), 검증(직접 실행하고 눌러 보고 테스트로), 판단(받아들일 것과 뺄 것을 내가 정함). 셋 중 하나라도 못 하면 그 부분은 아직 내 것이 아닙니다. 그럴 때는 "지금 배운 문법으로 풀어 써 달라"고 다시 요청합니다.

AI USE NOTE

AI를 쓴 만큼 짧게 적습니다. 사용량은 평가 기준이 아니고, 설명할 수 없는 코드·검토 없는 제출·출처 미기재가 감점입니다. 네 칸을 복사해 쓰세요. 각 시나리오 끝에 채운 예시가 있습니다.

AI USE NOTE
- 어떤 도구:
- 어떤 작업을 맡겼나:
- 무엇을 판단했나:
- 어떻게 검증했나:

PR 본문에는 한 줄로 줄입니다. AI USE NOTE: 도구 / 맡긴 작업 / 판단 / 검증. 팀 저장소의 AI-USE-NOTE.md(교안 저장소 templates/에서 복사)에 양식과 예시가 있습니다.

  • REQUIRED는 AI 활용 자체가 과제의 일부일 때입니다.

  • 맞습니다. 일부만 허용하고, 카드에 어느 부분인지 적습니다.

  • NO AI는 AI 없이 수행하는 과제입니다. 회고는 맞춤법·구조 정리까지는 허용합니다.

Q2OT의 금지선에 해당하는 것을 모두 고르세요.

  • 검증 없는 제출입니다.

  • 비밀정보 입력입니다. 키는 지우거나 가짜 값으로 바꿔 넣습니다.

  • 권장하는 사용법입니다. 설명을 듣고 내 말로 다시 말할 수 있으면 됩니다.

  • 무조건적 에이전트 권한입니다. 사람이 확인하는 지점이 사라집니다.

화면 읽기: 사이드바, 입력창, 응답

연습 화면을 열기 전에 실제 화면의 이름을 익혀 둡니다. 이름은 OpenAI 영어 문서의 라벨이고, 괄호 안은 뜻입니다. 한국어 화면의 표기는 조금 다를 수 있습니다.

사이드바(왼쪽)

New chat
새 채팅. 주제가 바뀌면 새로 시작합니다. 앞 대화가 섞이면 엉뚱한 파일 이름이나 가정을 끌고 옵니다.
Search
채팅·프로젝트·파일 검색. 단축키 Ctrl K(macOS ⌘ K). 필터는 All, Chats, Images, Documents, Projects.
Library
올리거나 만든 파일 보관함. Edu에 제공됩니다. 용량은 학교 설정에 따릅니다.
Projects
프로젝트. New project로 만들고, 안에 Chats와 Sources 탭이 있습니다. 팀 자료는 여기에 모읍니다.
Plugins
플러그인과 Skills. 예전의 GPTs는 2026년 12월 11일 퇴역 예정이라 수업에서 GPT 만들기는 다루지 않습니다.
Recents · Pinned
최근 대화와 고정한 대화. 대화 항목의 더보기(•••)에서 Move to project, Lock chat 등을 고릅니다.
Settings
아래 프로필에서 엽니다. Personalization(맞춤 설정·메모리), Data controls(공유 링크 관리)가 학생이 만질 곳입니다. 07에서 다룹니다.

Temporary

"캔버스(Canvas)"를 찾는다

예전 자료에 나오는 Canvas는 2026년 5월 이후의 모델에서 사라졌고, 관리자가 레거시 모델을 켠 경우에만 남아 있습니다. 지금은 응답 안의 편집 블록(writing block, code block)이 그 자리를 대신합니다. 이 페이지의 연습 화면에서도 오른쪽 패널을 '편집 블록'이라고 부릅니다.

답은 어떻게 만들어지나: 토큰, 컨텍스트, 확신

내부 동작
모델은 지금까지의 글(지시, 첨부 파일, 대화)을 보고 다음 토큰을 하나씩 고릅니다. 문장은 매끄럽지만 "사실 확인" 단계가 따로 없습니다. OpenAI 문서 원문: "Sometimes, it might sound confident—even when it's wrong." 컨텍스트 창 밖의 것(올리지 않은 파일, 메모리가 꺼진 지난 대화)은 모릅니다.
명세·문서
Does ChatGPT tell the truth? · Prompting 기초(목표·맥락·출력 형식·경계 네 요소)
트레이드오프
Thinking 슬라이더의 Instant는 빠르고, Medium·High는 더 오래 생각하는 대신 시간과 크레딧을 더 씁니다. 설명·초안은 Instant로 충분한 때가 많고, 원인 분석이나 여러 파일 비교는 더 생각하게 둡니다.

직접 실행해 확인하기: 세 단계

연습 화면에 나온 코드입니다. 실행하면 콘솔에 같은 TypeError가 납니다. 테스트를 하나씩 통과시킵니다. ① res.json() 앞에 await ② innerHTML 대신 요소를 만들어 textContent ③ res.ok가 아니면 상태 코드를 안내하고 멈추기. 네트워크 탭에서 요청과 상태 코드도 같이 보세요.

세 테스트를 모두 통과한 모습입니다. 막히면 비교해 보고, 그래도 모르는 줄은 "이 줄이 왜 필요한지 입문자에게 설명해 줘"라고 묻습니다.

async function load(url = '/api/items') {
  status.textContent = '불러오는 중…';
  const res = await fetch(url);
  if (!res.ok) {                                   // ③
    status.textContent = '불러오지 못했습니다 (' + res.status + ')';
    return;
  }
  const data = await res.json();                   // ①
  list.replaceChildren(...data.items.map((i) => {  // ②
    const li = document.createElement('li');
    li.textContent = i.title;
    return li;
  }));
  status.textContent = data.items.length + '개';
}

innerHTML에 들어간 사용자 입력: 왜 textContent인가

내부 동작
innerHTML은 문자열을 HTML 파서에 넘깁니다. 파서는 태그를 요소로 만들고, <img onerror> 같은 이벤트 속성은 요소가 만들어지면서 실행됩니다. textContent는 문자열을 텍스트 노드 하나로만 넣으므로 태그가 글자로 보입니다. 저장된 메모 제목처럼 "다른 사람이 쓴 값"이 화면에 들어갈 때가 위험한 순간입니다.
명세·문서
MDN · Element.innerHTML(Security considerations) · 5주차 교안의 textContent와 innerHTML의 차이
트레이드오프
innerHTML은 마크업 조각을 한 번에 넣기 편하지만 사용자 데이터에는 쓰지 않습니다. 서식이 필요하면 요소를 만들어 조립하거나, 서식 부분만 코드가 만들고 데이터는 textContent로 넣습니다. 12주차 검토 6묶음의 '보안' 질문이 바로 이것입니다.
5분 실험
메모 제목 하나에 태그가 들어 있습니다. 실행하면 빨간 경고가 뜹니다(제목 안의 코드가 실행된 것). innerHTML 줄을 요소 만들기 + textContent로 바꿔 경고가 사라지고 태그가 글자로 보이게 하세요.

대화 공유 링크

응답 위쪽의 Share로 읽기 전용 링크를 만듭니다. 링크는 만든 시점까지의 스냅샷이고, 이후 메시지를 넣으려면 Update and Copy Link를 다시 누릅니다. 기본은 익명 공유(Share anonymously)입니다. Edu에서는 같은 학교 워크스페이스 구성원만 열 수 있고, 관리자가 공유 자체를 꺼 둘 수도 있습니다.

그래서 AI USE NOTE에 대화 링크를 붙이면 강사·조교·팀원은 열 수 있지만, 공개 저장소를 보는 외부인은 못 봅니다. 공유가 꺼져 있으면 대화 내보내기(관리자가 허용한 경우), 캡처, 또는 쓸 만한 응답을 Add to project sources로 저장하는 방법을 씁니다.

Q1ChatGPT Edu에서 "내 대화를 학습에 쓰지 않는다"는 말의 뜻으로 맞는 것은?

  • 관리자는 컴플라이언스 도구로 대화에 접근할 수 있습니다. 다른 말입니다.

  • 맞습니다. "We do not train our models on your data by default"가 원문입니다.

  • 금지선입니다. 학습 미사용과 비밀정보 보호는 별개입니다.

Q2응답의 code block에서 Run 버튼으로 실행할 수 있는 것은?

  • JavaScript 실행은 문서화되어 있지 않습니다. 브라우저에서 직접 실행합니다.

  • 맞습니다. Python 샌드박스만 실행되고, 외부 웹 요청은 못 합니다.

  • HTML은 Preview로 모양만 볼 수 있을 뿐 실행이 아닙니다.

Q3"AI가 다 해 줘도 되나요?"에 대한 이 수업의 답은 세 단어입니다. 가운뎃점(·)으로 이어 쓰세요.

설명·검증·판단입니다. 내 말로 설명하고, 직접 실행해 검증하고, 받아들일 것을 내가 판단합니다.

Q4대화 공유 링크에 대해 맞는 것을 모두 고르세요.

  • 맞습니다. 이후 메시지는 Update and Copy Link를 눌러야 들어갑니다.

  • 맞습니다. 외부 사용자는 오류 화면을 봅니다.

  • 아닙니다. 외부인은 열 수 없으니 캡처나 내보내기를 함께 둡니다.
