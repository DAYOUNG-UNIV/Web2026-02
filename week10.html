에이전트 = 모델 + 하네스

에이전트는 두 부분으로 되어 있습니다. 모델은 글을 읽고 쓰는 AI 자체(Claude · GPT)로, 고를 수는 있고 바꿀 수는 없는 부분입니다. 하네스는 모델을 둘러싼 것으로 우리가 만드는 부분입니다: 도구(파일 읽기 · 고치기 · 명령 실행) · 지시 파일 · 문서 · 스킬 · 확인 방법 · 권한 · 기록. 도구는 Claude Code · Codex가 이미 갖고 있으니, 오늘 만드는 것은 저장소에 두는 파일과 설정입니다. 같은 모델이라도 저장소에 파일 몇 개가 있고 없고로 결과가 달라집니다(아래 '없을 때 · 있을 때').

훅은 정해진 순간에 Claude Code가 자동으로 실행하는 명령입니다. 설정 파일의 hooks 블록에 세 겹으로 적습니다: 언제(이벤트 · PreToolUse) → 어느 도구(matcher · Edit|Write · 비우면 전부) → 무엇을(command · 스크립트). 스크립트는 종료 코드로 답합니다: 0 통과 · 2 막고 이유(stderr)를 Claude에게 · 그 밖의 값은 경고만.

.claude/settings.json · hooks 블록
{
  "hooks": {
    "PreToolUse": [{
      "matcher": "Edit|Write",
      "hooks": [{ "type": "command",
        "command": "\"$CLAUDE_PROJECT_DIR\"/.claude/hooks/protect-files.sh" }]
    }]
  }
}
.claude/hooks/protect-files.sh · chmod +x
FILE=$(jq -r '.tool_input.file_path // empty')
for p in ".env" "package-lock.json" ".git/"; do
  if [[ "$FILE" == *"$p"* ]]; then
    echo "막음: $FILE" >&2; exit 2
  fi
done
exit 0
