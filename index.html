AI POLICY · 2026

AI 사용은 예외가 아니라 기본입니다

이 수업에서는 AI 활용을 기본적으로 허용하고 적극 권장합니다.
중요한 것은 AI를 사용했는가가 아니라 AI와 함께 어떻게 문제를 해결했는가입니다.

특정 AI 제품을 배우는 수업은 아닙니다

ChatGPT / Codex, Claude / Claude Code, GitHub Copilot, Cursor 등 어떤 도구를 사용해도 괜찮습니다.

수업에서는 특정 서비스의 버튼 위치보다 AI Coding Agent가 프로젝트를 읽고 → 작업하고 → 실행하고 → 검증하는 공통 원리를 배웁니다. 유료 서비스 이용 여부가 성적 차이로 이어지지 않도록 평가합니다.

과제마다 AI 활용 범위가 다를 수 있습니다

별도 안내가 없다면 기본적으로 AI Allowed 입니다.

AI REQUIRED

AI 활용 필수

AI와 협업하는 과정 자체가 학습 목표입니다.

AI ALLOWED

자유롭게 활용

대부분의 수업과 프로젝트에 적용됩니다.

AI LIMITED

일부만 활용

지정된 범위에서만 사용할 수 있습니다.

NO AI

AI 없이 수행

기초 개념을 직접 확인해야 할 때만 적용합니다.

AI가 만들었더라도 설명하고 검증할 수 있어야 합니다

모든 코드를 처음부터 직접 작성할 필요는 없습니다. 그러나 제출한 결과물의 핵심 구조와 동작, 중요한 설계 판단, 테스트 방법과 한계는 설명할 수 있어야 합니다.

검증 없는 제출

AI가 만든 코드나 글을 실행·검토하지 않은 채 제출하지 않습니다.

비밀정보 입력

API Key, 비밀번호, Access Token, 개인정보, 비공개 팀 자료를 외부 AI에 입력하지 않습니다.

확인하지 않은 정보 · 출처

AI가 제시한 사실, 논문, API, 라이브러리나 패키지는 원 출처에서 확인합니다.

무조건적인 에이전트 권한

파일 삭제, 패키지 설치, DB 변경, 배포, 유료 API 실행 등 영향이 큰 행동은 사람이 확인합니다.

AI USE NOTE

AI 사용도 작업 과정의 일부입니다

모든 프롬프트를 제출할 필요는 없습니다.
결과물에 실질적인 영향을 준 AI 활용을 짧게 기록합니다.

예시: "ChatGPT와 Claude Code를 사용했습니다. 아이디어 탐색에는 ChatGPT를, 프로젝트 파일 수정과 JavaScript 구현에는 Claude Code를 활용했습니다."

AI를 많이 사용하면 감점되나요?

아닙니다. AI 사용량 자체는 평가 기준이 아닙니다. 이해 · 판단 · 검증 · 수정이 평가의 핵심입니다.

이 수업에서 배우고 싶은 것은

AI보다 코드를 빨리 쓰는 사람이 아니라,
AI에게 일을 잘 맡기고 그 결과를 판단할 수 있는 사람입니다.
